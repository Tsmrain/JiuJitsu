# Herramientas de Desarrollo

## `volcar_todo_a_contexto.py`

Genera `docs/CONTEXTO_ARQUITECTURA_QWEN.md` volcando todos los archivos de
texto/código del proyecto en un único archivo Markdown, con índice, resumen
por extensión y referencias a binarios.

**Uso:**

```bash
python3 tools/volcar_todo_a_contexto.py --root . --out docs/CONTEXTO_ARQUITECTURA_QWEN.md
```
